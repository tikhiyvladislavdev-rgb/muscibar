БАР МЯТА · Music Bid Platform v4
================================

ЗАПУСК (рекомендуется — с поиском Deezer)
----------------------------------------
1. Установи Node.js (если нет)
2. В этой папке:
     node server.js
3. Открой в браузере:
     http://localhost:8787/index-v4.html   — гости
     http://localhost:8787/admin.html     — диджей (PIN по умолчанию: 1234)
     http://localhost:8787/hall.html      — экран зала / TV

Без Node тоже можно открыть HTML файлы напрямую,
но онлайн-поиск Deezer тогда недоступен (останется каталог + iTunes).


ФАЙЛЫ
-----
index-v4.html  — гостевая (все фичи)
admin.html     — админка
hall.html      — большой экран
server.js      — мини-сервер + /api/search (Deezer+iTunes)
shared.js      — общая логика
catalog.js     — локальный русский каталог
package.json   — npm start


ЧТО УМЕЕТ v4
------------
1. Автодополнение при вводе
2. Экран зала (hall.html)
3. PIN на админку (настройки → сменить)
4. Статусы заказа у гостя + «Мои заказы»
5. ETA «примерно через N мин»
6. Жанровые вкладки (Хиты / Русское / Застолье / 90-е / Иностранное)
7. Фильтр мата (badWords в настройках)
8. Мульти-настройки заведения (название, цвет, PIN, API)
9. Звук + вибрация при оплате / #1 в очереди
10. Мини-бэкенд поиска Deezer (node server.js)
+ Повтор заказа, топ сегодня, часто заказывают
+ Стоп-лист через поиск, все версии
+ Экспорт смены CSV
+ Превью телефонов (кнопка 📱)
