# MUSCIBAR v6 prototype

## Что добавлено
- `/player.html` — центральный плеер бара.
- `/music/` — локальная медиатека с Range streaming.
- `/api/library` — сканирование локальной медиатеки.
- `/api/player` — состояние и управление плеером.
- `/api/wave` — заготовка API для волны.
- режимы Queue / Wave / Party / Chill.
- автоматический переход на следующий трек.
- исправлена синтаксическая ошибка в catalog.js.

## Локальная музыка
Создай/используй папку `music` рядом с `server.js` и положи туда лицензированные аудиофайлы.

Рекомендуемый формат имени:
`Artist - Title.mp3`

Пример:
`Miyagi - I Got Love.mp3`

Открой `/player.html` на компьютере, который подключен к акустике бара.

## Важно
Deezer/iTunes в проекте используются как каталог/поиск и превью. Их preview URL не являются полноценной заменой лицензированного фонового воспроизведения. Для полноценного коммерческого playback нужно подключить источник, разрешающий такое воспроизведение.
